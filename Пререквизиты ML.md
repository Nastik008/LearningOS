# Пререквизиты ML

> [!abstract] Как пользоваться заметкой
> 1. Пройдите **самодиагностику** по каждому навыку (≈3–4 часа на всё).
> 2. По таблице [[#Маршрут подготовки]] определите, сколько недель нужно на подготовку.
> 3. Если подготовка нужна — делайте её **до** недели 1 основного плана [[ML-план-вариант-A]] по тому же шаблону недели (14 ч, практика ≥70%).
> 4. Навык считается закрытым, когда выполнен его **критерий готовности**.

Обозначения как в основном плане: **[проверь]** — не уверен на 100% в названии, цене, структуре или доступности ресурса.

Бюджет: все основные ресурсы бесплатные. Книги помечены как необязательные.

> [!important] Максимум подготовки — 4 недели
> Если по сумме выходит больше, всё равно стартуйте основной план через 4 недели. Оставшиеся пробелы закрывайте параллельно по 2 ч/нед. Бесконечная подготовка — одна из главных ловушек.

## 1. Python

**Зачем в ML.** Весь ML-стек — numpy, pandas, sklearn, PyTorch — на Python. Если вы спотыкаетесь о синтаксис, на ML-идеи не остаётся внимания.

### Самодиагностика

Решите без подсказок и без ИИ. Время — до 2 часов на все задачи.

- [ ] 1. Функция принимает список чисел и возвращает словарь `{"even": [...], "odd": [...]}`. Решить через comprehension.
- [ ] 2. Генератор, который построчно читает текстовый файл и отдаёт только строки, содержащие заданное слово.
- [ ] 3. `@dataclass Product(name, price, qty)` с методом `total()`. Отсортировать список товаров по `total()` по убыванию.
- [ ] 4. Функция `safe_divide(a, b)`: обрабатывает `ZeroDivisionError` и `TypeError`, возвращает `None` и печатает понятное сообщение.
- [ ] 5. Прочитать CSV модулем `csv`, посчитать сумму по числовой колонке, записать результат в JSON.
- [ ] 6. Декоратор `@timer`, который печатает время работы функции.
- [ ] 7. Частота слов в тексте через `collections.Counter`: топ-10 без учёта регистра и знаков препинания.
- [ ] 8. Класс `Money(amount, currency)` с `__repr__`, `__eq__`, `__lt__` и ошибкой при сравнении разных валют.
- [ ] 9. Функция с аннотациями типов, принимающая `Callable[[int], int]` и список, и применяющая функцию к каждому элементу.
- [ ] 10. Проект из двух файлов: модуль с функциями и `main.py`, который их импортирует; запуск через `if __name__ == "__main__":` с аргументами из `argparse`.

**Результат:** 9–10 — готовы; 6–8 — одна неделя прокачки; 5 и меньше — 2–3 недели.

### Ресурсы

**Если результат 5 и меньше (закрыть базу):**
- Stepik, «Поколение Python: курс для начинающих» — бесплатно. Быстро пройдите модули, где были ошибки; решайте все задачи модуля, не только «трудные».
- Stepik, «Программирование на Python» (Институт биоинформатики) — бесплатно, хорошо даёт работу с файлами и модулями.

**Если результат 6–8 (выйти на средний уровень):**
- Stepik, «Поколение Python: курс для продвинутых» — модули о функциях высшего порядка, файлах, модуле `csv`/`json` [проверь цену — курс может быть платным; при цене до 3000 ₽ укладывается в бюджет].
- Exercism, трек Python (exercism.org) — бесплатно, задачи с автотестами и возможностью получить ревью от ментора. Интерфейс на английском, но условия короткие.
- Codewars (codewars.com) — задачи 7–6 kyu. После решения обязательно читайте 2–3 лучших чужих решения: так вы быстрее всего учите идиомы Python.

**Книги (необязательно):**
- Дэн Бейдер, «Чистый Python. Тонкости программирования для профи» — декораторы, генераторы, dataclasses, идиомы. Лучшая книга для перехода от «пишу работающий код» к «пишу код как питонист».
- Лучано Рамальо, «Python. К вершинам мастерства» — справочник на будущее, не для чтения подряд.

**Справка:** Real Python (realpython.com) — статьи по конкретным темам (decorators, generators, dataclasses). Читать через встроенный переводчик браузера.

### Задачи для прокачки

**Уровень 1 — идиомы (8–10 ч)**
- [ ] 20 задач Codewars 7 kyu: строки, списки, словари
- [ ] Переписать 5 своих старых решений с циклами через comprehension, `zip`, `enumerate`, `any`/`all`
- [ ] 10 упражнений Exercism трека Python

**Уровень 2 — функции и классы (8–10 ч)**
- [ ] 15 задач Codewars 6 kyu
- [ ] Написать 3 декоратора: `@timer`, `@retry(n)`, `@cache` (свой, без `functools`), затем сравнить с `functools.lru_cache`
- [ ] Свой контекстный менеджер (`with Timer(): ...`) через класс и через `contextlib.contextmanager`
- [ ] Иерархия классов: `Shape` → `Circle`, `Rectangle` с методом `area()`; список фигур отсортировать по площади

**Уровень 3 — мини-проекты (6–10 ч, выбрать два)**
- [ ] **Анализатор логов:** читает большой лог генератором, считает ошибки по типам и часам, выводит отчёт в JSON
- [ ] **Трекер привычек в CLI:** команды `add`, `done`, `stats` через `argparse`, данные хранятся в JSON
- [ ] **Парсер банковской выписки:** CSV → расходы по категориям → топ-5 и среднее в день
- [ ] **Тесты:** к каждому мини-проекту 5+ тестов на pytest

### Критерий готовности
- [ ] Повторная диагностика: 9–10 из 10
- [ ] Задача уровня 6 kyu решается за ≤30 минут в 4 из 5 случаев
- [ ] Два мини-проекта в GitHub с тестами

## 2. git

**Зачем в ML.** Портфолио на GitHub — ваша визитка на собеседовании. В команде без git работать невозможно.

### Самодиагностика

Выполните в тестовом репозитории:

- [ ] 1. Создать репозиторий, `.gitignore` для Python, первый коммит
- [ ] 2. Создать ветку `feature`, сделать в ней 2 коммита, слить в `main`
- [ ] 3. Специально создать конфликт (одна строка изменена в двух ветках) и разрешить его
- [ ] 4. Отправить репозиторий на GitHub, открыть Pull Request из ветки и смёржить его
- [ ] 5. Отменить последний коммит, который уже отправлен на GitHub (`git revert`)
- [ ] 6. Временно спрятать незакоммиченные изменения (`git stash`) и вернуть их
- [ ] 7. Посмотреть историю одной строкой с графом веток (`git log --oneline --graph`)
- [ ] 8. Объединить 3 последних коммита в один (`git rebase -i`)

**Результат:** 7–8 — готовы; 6 и меньше — 3–5 часов практикума.

### Ресурсы
- **Learn Git Branching** (learngitbranching.js.org) — интерактивный тренажёр с русским интерфейсом. Разделы «Основы», «Двигаемся дальше», «Удалённые репозитории».
- **«Pro Git»**, Скотт Чакон и Бен Страуб — бесплатно на git-scm.com/book/ru. Гл. 1–3 (основы, ветвление), гл. 6 (GitHub).
- **Git How To** (githowto.com/ru) — короткие пошаговые уроки на русском.
- **Oh My Git!** — игра про git с визуализацией [проверь доступность].
- **GitHub Skills** (skills.github.com) — практические курсы прямо в репозиториях, на английском.

### Задачи для прокачки
- [ ] Пройти все уровни «Основы» и «Удалённые репозитории» в Learn Git Branching
- [ ] Повторить диагностику целиком на новом репозитории, каждую команду — по памяти
- [ ] Завести репозиторий `ml-journey` с README и структурой папок под этапы
- [ ] Все мини-проекты из раздела Python вести в отдельных ветках с PR в `main`
- [ ] Написать в Obsidian шпаргалку «git: 15 команд, которые мне нужны» и перенести её в Anki

### Критерий готовности
- [ ] Все 8 пунктов диагностики выполняются по памяти
- [ ] В `ml-journey` 10+ осмысленных коммитов и 2+ слитых PR

## 3. Командная строка

**Зачем в ML.** Серверы, Docker, удалённые машины с GPU и CI работают через терминал. Быстро заглянуть в большой CSV тоже удобнее командой, чем открывать файл.

> [!info] Если у вас Windows
> Установите WSL2 (Ubuntu): все команды ниже и дальнейшая работа с Docker пойдут через него.

### Самодиагностика

Скачайте любой CSV на 10 000+ строк с Kaggle и выполните:

- [ ] 1. Перейти в папку, показать файлы с размерами (`cd`, `ls -lh`)
- [ ] 2. Показать первые 5 строк файла (`head`)
- [ ] 3. Посчитать число строк (`wc -l`)
- [ ] 4. Найти строки с заданным словом и посчитать их (`grep`, `grep -c`)
- [ ] 5. Вывести уникальные значения второй колонки с частотами по убыванию (`cut`, `sort`, `uniq -c`)
- [ ] 6. Сохранить результат в файл (`>`), дописать в конец (`>>`)
- [ ] 7. Создать виртуальное окружение и установить пакет
- [ ] 8. Найти все `.py` файлы в папке и подпапках (`find`)

**Результат:** 6–8 — готовы; 5 и меньше — 4–6 часов практики.

### Ресурсы
- **Stepik, «Введение в Linux»** (Институт биоинформатики) — бесплатно, на русском.
- **Уильям Шоттс, «Командная строка Linux. Полное руководство»** — первая часть книги (необязательно). Английский оригинал бесплатно на linuxcommand.org.
- **OverTheWire: Bandit** (overthewire.org/wargames/bandit) — игра в терминале, уровни 0–15. На английском, но задания короткие.

## 4. Школьная математика

**Зачем в ML.** Логарифмы — в функциях потерь, экспонента — в сигмоиде и softmax, Σ — в каждой формуле, производные — в обучении любой модели. Это фундамент для этапов 1–3 основного плана.

### Самодиагностика

Решите на бумаге, без калькулятора, за 40 минут.

- [ ] 1. $2^3 \cdot 2^5 / 2^4 = ?$
- [ ] 2. $\log_2 32 = ?$
- [ ] 3. $\ln(e^3) = ?$
- [ ] 4. Решить: $3x - 7 = 11$
- [ ] 5. Решить: $x^2 - 5x + 6 = 0$
- [ ] 6. $\sum_{i=1}^{4} i^2 = ?$
- [ ] 7. $f(x) = \dfrac{1}{1 + e^{-x}}$. Найти $f(0)$
- [ ] 8. Производная $x^3 + 2x$
- [ ] 9. Длина вектора $(3, 4)$
- [ ] 10. $\log(a \cdot b) = ?$ (выразить через $\log a$ и $\log b$)
- [ ] 11. При каком $x$ функция $x^2 - 4x$ принимает минимальное значение?
- [ ] 12. Среднее чисел 2, 4, 6, 8

> [!note]- Ответы (не открывать до решения)
> 1. 16
> 2. 5
> 3. 3
> 4. x = 6
> 5. x = 2, x = 3
> 6. 30
> 7. 0,5
> 8. 3x² + 2
> 9. 5
> 10. log a + log b
> 11. x = 2
> 12. 5

**Результат:** 10–12 — готовы; 7–9 — неделя прокачки; 6 и меньше — 2 недели.

## 5. ML-английский

**Зачем в ML.** Документация, сообщения об ошибках, статьи и половина курсов — на английском. При уровне A1–A2 это не блокирует старт: план опирается на русские ресурсы. Но без словаря ML-терминов на этапах 9–12 станет тяжело.

> [!tip] Это дополнение к общему английскому, а не замена
> Цель здесь узкая: **читать техническую документацию** с минимальным переводчиком. Говорить и писать на английском для этого не нужно.

### Самодиагностика
- [ ] Откройте урок Kaggle Learn «Intro to Machine Learning» — первый урок. Прочитайте 1 абзац без переводчика и посчитайте незнакомые слова.

Не больше 3 незнакомых слов на абзац — читаете документацию с точечным переводом. Больше 3 — пока используйте переводчик браузера и наращивайте словарь.

### Ресурсы
- **Google Machine Learning Glossary** (developers.google.com/machine-learning/glossary) — официальный глоссарий терминов с объяснениями.
- **Kaggle Learn** (kaggle.com/learn) — микрокурсы простым английским; хороший первый текст для чтения.
- **Language Reactor** — расширение браузера с двойными субтитрами на YouTube (бесплатная базовая версия) [проверь].
- **Встроенный переводчик браузера** (Яндекс Браузер или Chrome) — для документации, но не для глоссария: термины учите сами.
